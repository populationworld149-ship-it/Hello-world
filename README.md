# Shopify theme

This repository contains a Shopify theme (assets/config/layout/locales/sections/snippets/templates).

## Develop locally

Install the [Shopify CLI](https://shopify.dev/docs/apps/tools/cli) and authenticate:

```bash
shopify login
```

Then, from this repo root:

```bash
shopify theme dev
```

## Deploy / publish

```bash
shopify theme push
```
